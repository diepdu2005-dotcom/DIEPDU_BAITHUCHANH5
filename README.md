## Hướng dẫn Build và Nạp code

1.  Mở project bằng KeilC.
2.  Nhấn `Build` (F7).
3.  Kết nối mạch nạp ST-Link và nhấn `Run` (F8) để nạp chương trình.
4.  Chạy Debugger
